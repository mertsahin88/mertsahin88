I build the tooling and context layer that let AI agents work safely inside enterprise systems.

At Lockheed Martin I work on AI developer tooling for SAP: an AI coding assistant for ABAP developers, Model Context Protocol servers that give agents governed access to SAP development, and a knowledge-graph pilot for change-impact analysis. Before that I spent sixteen years inside SAP systems, most recently as an SAP Technical Lead Consultant at Deloitte.

### Open source

**[abapmcp](https://github.com/mertsahin88/abapmcp)**: an MCP server that connects AI assistants (Claude, VS Code and others) to SAP ABAP systems through the ADT REST API. 69 tools for reading, writing, refactoring, RAP/CDS generation, debugging, ATC and unit tests. TypeScript, MCP SDK, vitest.

### What I work on

- Coding agents and harnesses (Claude Code, OpenAI Codex)
- MCP servers and tool design: read-only profiles, confirmation gates, sandboxing
- Knowledge graphs for code and change impact
- Multi-agent development: one agent specifies and reviews, another builds, and nobody accepts their own work
- Evals and quality gates for agent systems
